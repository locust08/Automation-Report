# M04 campaign creation database ownership

M04 uses only the following isolated CRM08 tables. Existing `ads_*` and `ads_media_plan_*` tables are not owned or altered by this module.

| Table | Purpose | Current mock use |
| --- | --- | --- |
| `m04_ads_ad_accounts` | Mock account identity and access evidence | Active |
| `m04_ads_budget_packages` | Currency and allocation envelope | Active |
| `m04_ads_campaign_plans` | Mutable workflow pointer and state | Active |
| `m04_ads_campaign_plan_revisions` | Immutable versioned plan | Active |
| `m04_ads_campaign_approvals` | Immutable approval evidence | Active |
| `m04_ads_campaign_builds` | Two-gate build state | Mock only |
| `m04_ads_campaign_build_resources` | Mock provider object mappings | Mock only |
| `m04_ads_campaign_gate_attempts` | Claims, retries, and reconciliation | Mock only |
| `m04_ads_campaign_qa_results` | Expected-versus-observed evidence | Mock only |
| `m04_ads_campaign_audit_events` | Append-only workflow audit | Active |
| `m04_ads_campaign_monitoring_handoffs` | Immutable M05-shaped handoff | Mock only; not sent to M05 |
| `m04_ads_google_campaign_revision_details` | Google V1 revision fields | Active |
| `m04_ads_meta_campaign_revision_details` | Meta V1 revision fields | Active |
| `m04_ads_tiktok_campaign_revision_details` | TikTok V1 revision fields | Active |

All provider identifiers generated by the mock workflow start with `mock-`. No Google Ads, Meta Ads, or TikTok Ads client is imported or called. Real provider adapters and M03/M05 publication require separate authorization and must translate only verified, non-mock records at that future boundary.
