## Scoped local repair

The M03 service now keeps a request-local, static stage label and emits a failure diagnostic with only stage, coarse category, curated blocker, outcome, provider-action indicator and correlation UUID. The same safe evidence is returned and logged as m03_pause_failure, allowing future lookup by the user-returned backend correlation. No raw message, stack, URL, header, input, token, principal identity or confirmation capability is logged. Categories are invalid_data, timeout, guard and unexpected; stages identify request validation, operator/grant checks, request/revision loading, preparation state, provider preview, confirmation creation and other existing workflow phases. No phase outcome or mutation authority is changed.

The companion DigitalBee feature branch accepts this optional diagnostic through an explicit strict stage/category schema and preserves it in safe preparation text. Old backend responses remain accepted. Unknown stages/categories/extra raw-error fields are rejected without leakage or POST retry.
